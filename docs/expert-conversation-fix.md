# 风险专家的聊天入口修正

2026-10-03

“分析样本风险”是隔离项目中的合成子专家示例，归属于综合整理专家，固定输入为 `synthetic-market.txt` 的具体资源版本。材料仅说明虚构 A 市场在样本期增长；没有真实市场数字或真实企业数据。此节点用于讨论样本真实性、统计口径、证据缺失与外推风险，不能当作已完成的真实市场分析。

## 界面

专家节点现在直接打开独立聊天页：滚动消息区、Markdown 回复、底部固定输入框。任务目标和分析状态位于标题下方；任务单、执行按钮、历史结果和回执由“任务与执行”弹窗打开；新要求和子专家入口放在“更多”菜单。移除了原任务详情页中间嵌套的追问表单。

普通对话使用固定专家方法、来源和已有结果，保存到该专家独立记录。显式提交“补充任务要求”会创建新任务版本，随后需要派发执行。对话不会自动重跑分析或覆盖结果。
