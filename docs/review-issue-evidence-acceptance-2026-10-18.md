日期：2026-10-18（Asia/Shanghai）。服务：http://127.0.0.1:8744/ ，已重启加载本轮接口。

## 功能

- 自动协作面板（执行 Agent 和评审 Agent）以及 Flow 的评审/反馈连线均可点击具体问题。
- 问题以执行任务 ID、被评审任务版本、该轮问题序号定位；不根据当前最新报告推测对象。
- 展示固定报告版本、报告/评审运行标识、报告哈希、相关工具列表；复用原有组件按需读取工具输入输出，并可展开对应报告全文。
- 默认只展示评审明确选中的调用。“查看本版本全部工具调用”另行展示全量，并明确不代表全部相关。
- 未定位到调用的问题只关联报告，不制造工具关联。

## 数据与校验

ReviewIssue 新增 tool_call_ids，允许为空，拒绝重复值。评审开轮上下文包含固定候选执行运行的调用目录。新增 read_execution_tool，只接受该目录内的调用 ID，通过原有 expert_run 接口读取经过校验的输入和确认输出；普通讨论不提供此工具。

保存评审前校验引用是否属于该候选运行。GET /api/review_issue 再次检查访问权限、报告哈希、任务/版本/结果对应关系和调用归属。内容撤权或哈希不一致时拒绝读取。复用原有存储，无新建追踪表、无旧记录回填。

程序校验记录身份和访问范围；关联由评审 Agent 选择，不等于证明根因或评审判断必然正确。
