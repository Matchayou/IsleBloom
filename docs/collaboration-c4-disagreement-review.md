## 本次修改

- 主助手比较流程明确先读目标结果版本的正文，再核对共同原始来源；历史总结、目录元数据和消息预览不能替代报告。

- 区分“专家观点是否对立”和“原始事实是否矛盾”；不能把专家意见一致当作独立证据。
- 保留基本算术，限制差值的业务解释；不能仅凭原文有没有“冲突”一词裁定矛盾，也不能重复计算重叠的口径差异。
- 追问采用中性问题，要求依据、适用条件与未知项；最终答案须纠正历史讨论中的错误。

## 该样例应得出的判断（本次人工审阅）

1. A、B 报告对“口径不同、缺少复算依据”的核心判断基本一致；这不能证明数字本身正确。
2. `21% − 12% = 9` 个百分点是成立的算术。因为统计口径不同，这个差值不能直接解释为真实市场变化、优劣或因果效应。
3. 已知的是分母、调整与门店覆盖存在差异。差异如何影响数值、解释了多少百分点，资料没有提供依据；不能把重叠描述当成多个独立原因。
4. 缺少统一口径下的计算资料，无法判定两数字统一口径后是否冲突，也无法选定哪个更可信。不能从未出现“冲突”这个词推导出不存在事实矛盾。
5. 缺少原始分子分母、指标定义、期间与范围、小店定义、调整方法及换算依据。现有资料无法补齐时，应明确这些缺口，并保留待复核状态。
