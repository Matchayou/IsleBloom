## 引用到底修好了什么

最初失败来自把工作记忆 ID 填入文件引用。摘要、专家指令和引用 schema 已明确：历史检索 ID 不等于 ResourceRef；只有历史依据的声明注明历史来源及文件证据缺口。

首轮完整复验又暴露引用元数据被改写的问题：24 次中 8 次引用拒绝、1 次私有笔记读取失败，只有 15 次交付。随后复用现有输出修正循环，加入只读证据预校验：模型收到原文匹配错误后，只在已有证据上修正；关闭工具，预算不增加，最终仍由原校验器验收。

最终批次的三次现金流任务都触发了引用修正，三次均通过；其中一次先修 JSON、再修引用，两种修正共用预算。总计 9 次 JSON/schema 修正和 3 次引用修正，没有引用校验导致的终止，也没有记忆 ID 混用导致的交付失败。

这是本轮观察到的恢复能力，不代表今后不会出现引用错误。首轮私有笔记不存在的问题未在最终批次重现，本次没有修改该行为，不能宣称已修复。

## 五次语义失败的具体含义

| 试验 | 实际问题 | 正确理解 |
|---|---|---|
| Q02，第 2 次 | 把 2024 年乙描述为无法充当 2023 年甲的“上年同期基数” | 讨论 2023→2024 时，2023 是基期、2024 是本期；应先对齐同一主体和币种 |
| Q02，第 3 次 | 公式写对 `(90−80)/80=12.5%`，文字却称分子为 90 | 增长率分子为 `90−80=10`，分母为 80 |
| Q03，第 3 次 | 表格、字段、引文均为 105，正文收入段出现“125 台” | 应为 105；125 没有资料依据 |
| Q04，第 3 次 | 一处把年份列入“任何一项不一致都足以”否定可比性的条件，另一处又说年份不同本身不构成障碍 | 年份不同本身正常；本题真正不一致的是地域、样本范围和纳入规则 |
| Q07，第 2 次 | 正确算出 5，却把“历史旧讨论的具体内容”列入缺失资料 | 独立算式信息已齐，不需要补旧讨论 |

这些错误没有改写原始输出。对应的逐项诊断、报告原文、引文和工具轨迹均保存在 trial 目录。Q04 另有两份输出附加的证据需求措辞冗余，已在诊断记录中提示人工复核，没有把观察项悄悄改成新的评分规则。
