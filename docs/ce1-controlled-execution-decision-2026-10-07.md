# CE1：受控工具执行与逻辑数据隔离

2026-10-07，依据用户明确指令替换原 Docker / 强隔离方案。本文件及更新后的增量计划是当前要求；此前容器方案和验收日志只保留为历史记录，不再构成验收门槛。

## 执行边界

保留 OpenAI Agents SDK 0.22.2、DBOS 3.0.0、PostgreSQL、既有资料权限和正式提交路径。SDK 在可信应用内运行，经 `controlled/` broker 调用固定提供方和显式工具。没有 Docker 后端、自动切换或旧协议兼容。

CE1 仅开放 `read_source`、`search_source`、`write_private_note`、`read_private_note`。模型不能选择工作区路径、提供方、执行身份或数据库连接；不提供 Shell、任意 Python、任意文件路径和任意 HTTP 代理工具。服务本身和工具实现是可信代码，不能承诺抵御同 OS 用户运行的任意代码。

私有目录按研究、会话与授权世代绑定，保存 SQLite 索引、哈希校验文件、完整工具结果和请求记录。逻辑隔离由工具白名单、参数校验、scope/固定版本、服务端工作区选择共同实现。私有笔记不是正式证据、授权或已采用成果。

## 当前验收矩阵

| 要求 | 实现与验收方式 |
| --- | --- |
| 真实模型闭环 | 使用用户授权的 DeepSeek 凭据运行 SDK，读取合成验收源、写入重读笔记、返回结构化成果；验证来源标记和未知信息表达 |
| 持久预算 | 模型/工具请求前在真实 PostgreSQL 预占；拒绝重复操作和超限；新进程不重置累计用量，未返回用量保持 unknown |
| 取消 | 持久化 task/spec 取消，取消并等待 SDK 协程，阻止迟到工具和成功发布，保留未知请求用量；不声称能撤回服务商已经收到的请求 |
| 私有持久化 | SQLite/文件原子保存与哈希检查，关闭后用新进程重读；错误路径和跨逻辑工作区读取被拒 |
| 身份与并发写者 | 身份由准入固定、每操作前后复核；单写者凭证与世代拒绝竞争/过期写者；不按时间抢占失联写者 |
| 提交回执 | broker 接收不等于发布；沿用 TaskLedger/TaskReceipt；保存重试返回同一结果和回执、不新增模型调用 |
| 逻辑权限 | 禁止未注册工具、身份伪造、越权资料和路径；撤权后禁止旧绑定的调用与提交 |

删除的验收项：镜像构建、容器非 root、只读根文件系统、network=none、seccomp/capabilities、容器内凭据不可见、CPU/内存/进程硬限额、持久卷硬磁盘配额、容器移除及任意子进程树清理。这些属于范围删除，不标记为已通过。

## 运行与数据范围

`build_ce1_tasks(..., private_root=..., model_provider=...)` 是当前 CE1 验收入口。`scripts/verify_ce1_live.py` 使用新建 `ce1_` PostgreSQL 数据库、每次全新输出目录；凭据仅通过进程环境注入。模型/数据库未通过前保持 CE1 待验收，不自动切换历史产品入口，不进入 CE2。

现有 PostgreSQL 每 OS 用户执行锁和数据库 advisory lock 保持原样。宿主锁空闲时可以直接执行；若已占用，验收明确阻塞，不删除锁或停止历史服务。故障恢复仍受既有任务级语义约束，不承诺从每次模型调用精确续跑。

后续 CE2 的多入口逻辑隔离沿用此边界。CE5 的 worktree 规划保留，但任意仓库脚本/构建测试执行不能借本次变更自动授权；到该阶段先明确可用的受控工具范围和可信执行条件。
