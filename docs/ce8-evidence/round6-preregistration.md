## 固定比较

三项合成中文业务任务 × 三种输入策略，共九次真实运行。模型 deepseek-flash，DeepSeek Responses，SDK 0.22.2，max_retries=0；固定 synthesize 方法、14 次模型 / 12 次工具 / 360 秒。任务、历史、资料内容、判定项目固定在 evals/ce8/fixtures.json；每次独立研究、scope、run、私有目录与数据库，资料身份可以不同但内容 SHA 必须相同。顺序为每题 full、projection、compaction，不选择最佳样本替换失败。

- full：仅评测程序将 ContextBuilder 投影替换为完整 PreparedInput，关闭摘要；保留相同受控 SDK、权限、账本、工具、原始限额和模型窗口预检。不是恢复旧后端。
- projection：产品确定性业务/运行时投影；仅评测程序关闭摘要。
- compaction：未经替换的产品投影加增量摘要。

三个策略在评测程序外不提供开关。完整输入须适配相同模型窗口；若超过窗口或预算，保留失败，不提高该组限额。评测代码也登记 hash。语义修复如改变产品方法，必须保留旧轮、冻结新轮并重跑受影响的完整三组对照，不偷偷重试到成功。

## 先验判定

每题逐项人工阅读完整报告与真实工具读回，不以关键词命中或模型自评代替判断。fixtures 中每个 expected 项计一项：正确且有资料/历史依据才计 1，遗漏或矛盾计 0；必需证据召回与约束保留分别计分。固定版本错用、越权读取、虚构审核/采用/验证通过任一出现即阻断，不接受平均分抵消。最终产品 compaction 三题必须全部项目通过，三份交付均 pending_review，所有必需固定资料实际读取；基线失败保留用于比较，不据此降低标准。

设备题检查中文同义称谓、长历史中段代号、用户纠错、固定 v1 与 v2 草案区别、旧配色问题不覆盖当前事实核对、设备单位已知与收入未知分别表达。财务题检查跨报告 CFO/经营活动现金流、资本性支出、自由现金流公式、12.5% 算术与币种/主体范围不同导致不可比之间的区别。订单题检查订单/出货/验收不等同、冲销与测试单、无分母不得计算市占率、最新预测不能覆盖固定快照。

同时记录：每题语义项目、证据读取和版本、重复读次数（完全相同工具名和参数额外调用）、用户约束、交付、模型输入 token/原始请求字节、模型/工具调用数、端到端秒数、已知 input/output/cache 与 usage.complete。未知用量标记未知，缓存包含在 input 内不重复相加；不按未经核实的价格换算费用。摘要请求也计入总成本。不预设压缩一定降低短任务成本。

## 第五轮预登记（定位窗口投影实现缺口后）

第四轮 orders/compaction 的实际 manifest 在 model:3 起把 index=0 的已验证 business:history 摘要以 request_budget 外置；model:4 后还把 runtime 摘要外置。模型保留长原文页，却失去已找到的关键工作记忆，继续重读并遗漏笔记。故第三/四轮提示词调整未关闭此实现缺口，第四轮仍不通过。
